# Is the payment link compatible with WooCommerce?

Collection: Lenco by BroadPay

Original article: [view source](https://support.lenco.co/en/articles/8229205-is-the-payment-link-compatible-with-woocommerce)

Yes, the payment link for Lenco by BroadPay, for Zambian Merchants
is compatible with WooCommerce. We offer a plugin that supports
the payment link on WooCommerce.
