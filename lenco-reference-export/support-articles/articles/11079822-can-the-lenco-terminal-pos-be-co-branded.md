# Can the Lenco Terminal (POS) be co-branded?

Collection: Lenco Terminals (POS)

Original article: [view source](https://support.lenco.co/en/articles/11079822-can-the-lenco-terminal-pos-be-co-branded)

Yes, the Lenco terminals can be co-branded; however, this request
is subject to a bulk number of 200 machines.

All other requests less than 200 will not meet the criteria for
this request with us.
