# How can I get the Lenco Token App?

Collection: Security & Privacy

Original article: [view source](https://support.lenco.co/en/articles/6827386-how-can-i-get-the-lenco-token-app)

There are two ways you can receive OTPs:

1. Via email: You can get OTP via email when you log in or make transactions.
2. Via the Lenco Token App: you can setup the [Lenco Token App](https://onelink.to/h8vtep%5C) on your phone, which will automatically generate OTPs for you each time you need it.
3. Download the [Lenco Token App for Android](https://play.google.com/store/apps/details?id=co.lencotoken).
4. Download the [Lenco Token App for iOS](https://apps.apple.com/us/app/lenco-banking-token/id1569340897).
