Does Lenco have APIs for developers?

Collection: API

Original article

You can build financial services products with the Lenco API. The API covers automated disbursement, virtual accounts, and bill payment.

You can access your Lenco account, sub-accounts, and transaction histories programmatically with the Lenco API.

We created easy-to-follow documentation to help you build excellent web and mobile integration payment experiences with the Lenco API.

The documentation covers the available endpoints and provides example codes for using the API. They will help you build your admin tools or automate processes that previously had to be performed manually.

  • You can find the Lenco API documentation at - https://lenco-api.readme.io/
