# Does Lenco have APIs for developers?

Collection: API

Original article: [view source](https://support.lenco.co/en/articles/6423891-does-lenco-have-apis-for-developers)

You can access your Lenco account, sub-accounts, and transaction
histories programmatically with the Lenco API.

We created easy-to-follow
[documentation](https://lenco-api.readme.io/)
to help you build excellent web and mobile integration payment
experiences with the Lenco API.

The documentation covers the available endpoints and provides
example codes for using the API. They will help you build your
admin tools or automate processes that previously had to be
performed manually.

- You can find the Lenco API documentation at - [https://lenco-api.readme.io/](https://lenco-api.readme.io/)

If you have any questions or need support as you build on the
Lenco API, send us an email at
[developers@lenco.co](mailto:developers@lenco.co)
