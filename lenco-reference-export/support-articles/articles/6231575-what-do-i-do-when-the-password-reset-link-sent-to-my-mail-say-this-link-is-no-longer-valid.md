# What do I do when the password reset link sent to my mail say " This link is no longer valid"

Collection: Security & Privacy

Original article: [view source](https://support.lenco.co/en/articles/6231575-what-do-i-do-when-the-password-reset-link-sent-to-my-mail-say-this-link-is-no-longer-valid)

If the reset password link shows as " this link is no longer
valid" kindly visit your dashboard and re-click on "Reset
Password"
N.B. The reset password link expires in 30 minutes
