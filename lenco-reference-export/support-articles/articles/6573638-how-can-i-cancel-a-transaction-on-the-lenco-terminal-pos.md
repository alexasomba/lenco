# How can I cancel a transaction on the Lenco Terminal (POS)?

Collection: Lenco Terminals (POS)

Original article: [view source](https://support.lenco.co/en/articles/6573638-how-can-i-cancel-a-transaction-on-the-lenco-terminal-pos)

A transaction can be cancelled using the Red Button on the machine
if the cardholder has not authorized the transaction with their
CARD PIN.

Where the customer has already inputted their PIN then the
transaction can no longer be cancelled.
