Split Payments and How to split inflows?

Collection: Making and receiving payments

Original article

Lenco gives you control to set instructions for inflows to be splitted into your sub accounts.

Split payment is a control you have on your Lenco account to set up automatic splitting of inflows into different sub accounts.

The only condition that needs to be passed to set and control split payment is that you must have created a maximum of 5 sub-accounts because the split has to be done across the sub-accounts.

To set Split Inflow, follow the steps below:

  • Log in to the Web

  • Go to Settings

  • Click on Account Settings

  • Then Account Rules

  • Select Split Inflow instruction
