# AutomaticPallet writing for humans

Use across all lifecycle stages for human-facing prose. Keep the user’s meaning and technical precision intact.

## Writing pass

1. Remove filler, puffery, hedging, generic chatbot language, and repeated conclusions.
2. Replace abstract claims with concrete behavior, decisions, evidence, or next actions.
3. Keep sentences direct and vary rhythm naturally; prefer plain language over jargon.
4. Preserve exact commands, identifiers, file paths, code, and quoted technical text.
5. Self-audit for missing context, unsupported claims, and a tone that does not sound like the intended human author.

## Repository boundaries

- Do not rewrite code or technical identifiers while polishing prose.
- Do not silently change policy, authorization, workflow, or product decisions.
- Do not use this skill to justify external uploads, PR edits, review triggers, or thread resolution.
